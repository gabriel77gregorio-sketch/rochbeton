# Ladrilhos Rochbeton — Website Institucional & Catálogo Interativo

Website institucional e catálogo interativo da **Rochbeton**, tradicional fabricante de ladrilhos hidráulicos artesanais atuando desde 1985 em Taboão da Serra/SP.

Desenvolvido com foco em alta performance, arquitetura editorial e design sofisticado inspirado no estilo visual da Apple e no conceito de **Liquid Glass (Glassmorphism)**.

---

## 🏛️ Funcionalidades & Pilares

- **Header Flutuante Liquid Glass:** Barra de navegação com `backdrop-blur-xl`, logotipo oficial transparente, âncoras suaves e botão direto para atendimento no WhatsApp.
- **Hero Editorial:** Apresentação da tradição cimentícia de 1985, diferenciais ecológicos (100% cura na água, 0% queima) e showcase fotográfico em alta resolução.
- **Pilar 1 — Galeria de Projetos Reais (Obras Aplicadas):** Filtros por ambiente (*Cozinhas, Varandas, Banheiros, Salas, Fachadas*) e recurso **Spotlight / Peça Usada**, revelando a peça do ladrilho aplicada na foto e botão de orçamento com mensagem pré-formatada.
- **Pilar 2 — Catálogo & Portfólio Completo:** Abas por categorias (*Decorados 20×20 e 15×15, Hexagonais, Antiderrapantes, Linha Podotátil NBR 9050, Faixas & Rodapés, Tosetos*), hover com preview de paginação e **Ficha Técnica Completa para Arquitetos e Especificadores**.
- **Pilar 3 — Simulador de Ambientes 3D:** Maquete interativa com visualização de paginação, troca de ambientes, alternância de modelos de ladrilho, 4 opções de rejunte cimentício, ajuste de escala/densidade (2x2, 3x3, 4x4) e calculadora de peças/m².
- **A Fábrica & Tradição (1985):** Linha do tempo dos 4 passos artesanais e seção para **Restauração Patrimonial de Imóveis Históricos e Tombados**.
- **Área do Arquiteto:** Solicitação de caixa de amostras físicas, download de texturas 3D / Blocos BIM (SketchUp, Revit, 3ds Max) e catálogo em PDF.
- **Localização & Showroom:** Dados reais da fábrica em Taboão da Serra/SP, mapa do Google Maps integrado, horários e botão flutuante permanente de WhatsApp.

---

## 🛠️ Stack Tecnológica

- **Framework:** [Astro](https://astro.build/) (Arquitetura Islands)
- **UI & Interatividade:** React 19 (`client:visible` sob demanda)
- **Estilização:** Tailwind CSS v4 com variáveis de tema e utilitários Liquid Glass
- **Tipografia:** Playfair Display (editorial) & Plus Jakarta Sans (interface contemporânea)
- **Ícones:** Lucide Icons & vetores SVG cimentícios

---

## 🚀 Instalação e Execução Local

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build estático de produção
npm run build

# Pré-visualizar build local
npm run preview
```

Servidor padrão em `http://localhost:4321/`.
